# Vantix AI Stack – Project Roadmap

This roadmap outlines the phased development of a multi-agent AI ecosystem powering:
- **NeuroClash**: An AI-driven strategy game
- **AetherChain**: An autonomous product launch system
- **EchoSoul SDK**: A dynamic NPC system for game engines

---

## Phase 1: Core Infrastructure (Weeks 1–2)

- [x] Create GitHub repo and project file structure
- [ ] Set up unified AI agent library (planner, analyzer, executor, communicator)
- [ ] Create shared memory and task orchestration modules
- [ ] Deploy Unity environment for training and simulating agents (NeuroClash)
- [ ] Build API automation for Gumroad (AetherChain)

---

## Phase 2: Project Modules (Weeks 2–4)

### NeuroClash
- [ ] Build base defense/capture map in Unity
- [ ] Integrate ML-Agents Toolkit for agent training
- [ ] Train initial agents using PPO/self-play
- [ ] Add procedural map generator using LLM and noise algorithms

### AetherChain
- [ ] Develop TrendScout (Reddit/Steam scraper)
- [ ] Build CopySmith (tagline and product copy generator)
- [ ] Launch DropBot (product publisher to Gumroad with schedule)
- [ ] Route revenue to external wallet

### EchoSoul SDK
- [ ] Develop Unity plug-in to replace NPCs with LLM-driven agents
- [ ] Add long-term memory and vector search via ChromaDB or FAISS
- [ ] Implement personality, emotion arcs, and dynamic interaction modules
- [ ] Integrate facial animation using NVIDIA Audio2Face or alternatives

---

## Phase 3: Mesh Integration (Weeks 5–6)

- [ ] Connect all agents to shared intelligence layer
- [ ] Enable AI-to-AI communications (NeuroClash agents feed EchoSoul insights, AetherChain drops dynamic expansions)
- [ ] Build central control interface for managing AI deployments, drops, and simulations

---

## Phase 4: External Expansion

- [ ] Release SDK publicly for Unity and Godot
- [ ] Launch NeuroClash alpha on Steam or Itch.io
- [ ] Begin monetized drops through AetherChain product engine
