# Vantix Command Center – Web UI

This will be the frontend interface for managing and monitoring all Vantix AI agents in real time.

## Planned Features
- Agent registration panel
- Task queue monitor
- Agent state viewer (memory, emotion, recent actions)
- Manual task triggers (buttons to launch products, talk to players, etc.)
- Live system logs (streaming with Socket.IO)
- Mobile and desktop friendly

## Stack
- React + Tailwind CSS
- FastAPI or Flask backend
- Socket.IO or WebSockets
- Optional Unity/WebGL bridge
